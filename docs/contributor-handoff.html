Pull the latest main branch and follow the README for local setup. The existing v0.2.2 download does not contain these new source changes; build from current source. Writing decoder now offers writing inside Bandstand or across apps. Use synthetic data first, then verify with a Muse headset and a fresh Mac account.

  1. Exercise every activity end to end. Test every ERP and time-frequency paradigm, questionnaires and social task, meditation, Find Your Reset, and both writing modes. Verify instructions, start/stop, timing, live feedback, per-channel artifact rejection, saving, reopening results and exports. Identify and finish placeholders; do not label unvalidated psychology estimates as validated results.
  2. Review UI and results for each activity. Check compact and large windows, navigation, dialogs, keyboard controls, clear recording state, readable graphs, units, analysis windows, uncertainty and empty/error states. Prioritize data that help a novice understand the task and result.
  3. Finish backend integration and acceptance testing. Verify signup, confirmation, recovery, persistent sign-in, deletion and opt-in ERP upload against Supabase, including cross-account isolation and withdrawal. Protected shared writing-decoder training is not implemented: design and test secure multi-participant aggregation, privacy protections and model versioning before enabling uploads. Raw writing, EEG, embeddings and personal checkpoints containing phrase banks must stay local. Do not equate a sharing preference with a working upload pipeline.

Record pass/fail evidence, remaining blockers and hardware-tested versus simulated checks. Preserve stable application signing identity across updates to avoid repeated macOS permission failures.
