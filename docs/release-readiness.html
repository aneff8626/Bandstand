Bandstand — 8 October 2026

Development contributor build. This is not a validated participant release.

Implemented and checked

  • Separate sign-in, signup, verification, recovery, account and sharing dialogs; explicit close controls.
  • Optional Keychain refresh-token persistence and rotation. Passwords are not stored by Bandstand.
  • ERP opt-in upload, listing, consent withdrawal and deletion. Cloud access controls tested using two synthetic accounts in a rolled-back transaction; no participant data uploaded.
  • Cloud tests: denied upload without consent, idempotent duplicate, isolation between accounts, own-record deletion, withdrawal blocking new uploads, no direct table access and malformed/private-text payload rejection.
  • Confirmation/recovery email templates saved with in-app codes. Real delivery/recovery still needs a user test.
  • 90 Python tests and all JavaScript regressions passed. Synthetic 100-trial processing/export benchmark: 150 seconds of EEG in 4.83 seconds; 60.94 ms p95 per 1.5-second block; 88.5 MiB peak process memory. Not a sustained GUI or hardware benchmark.
  • Standalone Apple Silicon build bundles Python, scientific/decoder dependencies and the pinned public encoder. Offline synthetic embedding test passed.
  • Native startup race fixed: initialization waits for all scripts. Native account, signup, sharing and close navigation checked.
  • Source audit: explicit allowlist, secret/identity pattern search and exact private-text comparison. Only audited source and clean bundle intended for publication.

Still outstanding

  1. Headset acceptance: connect, disconnect/reconnect, packet loss, signal quality, and experiment operation with real Muse hardware. Physical stimulus timing needs measurement.
  2. Fresh Mac installation: macOS permissions and Gatekeeper behavior. Build is ad-hoc signed, not Developer ID signed/notarized; Intel and other platforms are not packaged.
  3. Account acceptance: real new confirmation and recovery emails, expired/reused codes, persistent sign-in across restart, deletion with a designated test account. Automated tests do not prove mail delivery.
  4. Protected shared decoder training: not implemented. Requires a defined shared model, multi-participant secure aggregation with dropout handling, participant-level clipping/noise and privacy accounting, cohort minimums, authenticated round orchestration, model versioning and adversarial tests. Do not upload existing personal checkpoints; they contain phrase banks.
  5. Research operation: provider retention policy, quotas/monitoring, researcher analysis/export workflow, and study-specific consent/validation remain to be finalized.
  6. Scientific validation: local semantic retrieval is exploratory and may reflect motor/eye activity. It is not demonstrated intended-communication decoding.

Raw writing, embeddings and personal decoders remain local. Sharing interest does not authorize future decoder uploads.
