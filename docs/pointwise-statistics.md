# Pointwise statistics drawer

Open **Stats** in an ERP or spectral Run/Results view. Choose a condition pair, a single sampled coordinate or a range, and a correction. Inputs update automatically. “Use plot selection” copies the current mean-amplitude interval or spectral band. The Provisional drawer also contains Analyze frequencies and By condition / Each block. Each ERP, spectrum and time–frequency graph has its own highlight checkbox. Correction menus beside the graphs and in Stats stay synchronized (FDR/BH by default; BY, Holm and uncorrected also available). The annotation checkbox controls purple significance marks; closing the drawer retains the last calculated snapshot. Optional live updates recompute after completed trials/blocks; the panel states the snapshot count. Standard band/mean-amplitude analyses and exports are unchanged.

ERP tests use all channel-accepted trials, not the 20 recent waveforms drawn for illustration. Each sampled latency gets a two-sided Welch test (minimum three trials per condition). This assumes independent trials and an adequate sampling distribution; very small samples are uncertain. Speller tests use calibration trials only and do not validate the learned classifier.

Spectral tests use native 0.5 Hz PSD bins, transformed to log power, with the existing provisional moving-block bootstrap. Clean non-overlapping two-second observations retain trial boundaries and artifact gaps. Dependence, drift and data-length checks remain active; the drawer does not convert overlapping windows into independent observations. See spectral-statistics.md for estimator limitations. The bootstrap's 999 resamples give a minimum p-value of .001; a large Holm family can therefore have no discoveries even with strong apparent differences.

The app corrects over the full recorded epoch or the full 2–40 Hz spectrum × all recorded electrodes for one selected condition pair. Selecting a smaller inspection range does not shrink this family. Unavailable tests count as p=1 so data-dependent exclusions cannot shrink the correction family. Holm controls family-wise error under arbitrary dependence between valid tests. Benjamini–Yekutieli controls false discovery rate under general dependence; Benjamini–Hochberg assumes independence or positive dependence. An explicitly uncorrected option is available for comparison. Alpha is .05. Point tables expose raw and adjusted p, condition sample counts, and condition A minus B differences. Purple marks indicate adjusted p below .05 when corrected, or raw p below .05 when uncorrected; the plot labels the method. Stats sits beside Star and Delete; Supplemental Results holds trial quality and the rejection log.

Time–frequency map analysis uses a separate Welch test at each aligned time–frequency cell, with one observation per block and at least three blocks per condition. The family includes all recorded cells × electrodes. Purple outlines appear on both compared condition maps. This assumes independent blocks; overlapping windows are never counted as extra independent blocks.

None of these methods corrects arbitrary pair exploration or repeated live looks, repairs invalid base tests, removes condition/time confounding, or supports population inference from one recording. Significant adjacent samples do not establish an exact component onset/duration. Results remain exploratory.

References: [MNE multiple-testing documentation](https://mne.tools/stable/generated/mne.stats.fdr_correction.html) and [MNE statistical inference](https://mne.tools/stable/auto_tutorials/stats-sensor-space/10_background_stats.html).
